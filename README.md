# ControleEstoqueApp

Sistema de Controle de Estoque desenvolvido em **C#** utilizando **Windows Forms (WinForms)** no **Visual Studio**.

## 📌 Sobre o Projeto

O **ControleEstoqueApp** é uma aplicação desktop voltada para o gerenciamento de produtos em estoque. Permite cadastrar, editar, excluir e listar produtos de forma prática e eficiente.

## 🛠️ Tecnologias Utilizadas

- [C#](https://learn.microsoft.com/dotnet/csharp/)
- [Windows Forms](https://learn.microsoft.com/dotnet/desktop/winforms/)
- [Visual Studio](https://visualstudio.microsoft.com/)
- Banco de dados local (ex: SQLite ou SQL Server Express) *(ajuste se necessário)*

## ⚙️ Funcionalidades

- Cadastro de produtos
- Edição e exclusão de registros
- Consulta de produtos em estoque
- Interface gráfica amigável
